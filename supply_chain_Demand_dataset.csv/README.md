Machine Learning-Based Supply Chain Demand Forecasting and Inventory Analysis

Project Overview

This project focuses on analyzing supply chain data, forecasting product demand using Machine Learning, and understanding inventory requirements.

Objectives

- Analyze historical product demand.
- Identify monthly demand trends.
- Predict future product demand.
- Analyze inventory stock levels.
- Estimate reorder levels using demand and supplier lead time.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Machine Learning Model

Linear Regression was used to predict product demand based on historical demand and time-related features.

Model Evaluation

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

Dashboard

The project includes four visualizations:

1. Monthly Demand Trend
2. Actual vs Predicted Demand
3. Product-wise Inventory Stock
4. Product-wise Reorder Level

Key Business Metrics

- Total Revenue: ₹1,342,095,000
- Total Quantity Sold: 191,219
- Total Products: 10
- Average Lead Time: 7.5 days

Dataset

The project uses a synthetic dataset created for educational and portfolio purposes.

Conclusion

This project demonstrates how Python and Machine Learning can support demand forecasting and inventory analysis through data-driven insights.
